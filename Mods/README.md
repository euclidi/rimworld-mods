# Mods

Each child directory with About/About.xml is one mod. Use a unique package ID (euclidi.*), supportedVersions containing only 1.7, and explicit metadata for any dependency. Keep C# in Source, compiled mod assemblies in Assemblies, and standard RimWorld content directories at the mod root.

DevelopmentProbe: minimal no-DLC startup logging and packaging test, no game mechanics.

Orcish Hordes: planned custom species and factions, pending scope and race-framework approval. Do not publish placeholder packages as gameplay releases.
