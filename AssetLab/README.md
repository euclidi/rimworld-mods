# Asset lab

Match vanilla RimWorld visual grammar. Reference [texture documentation](https://rimworldwiki.com/wiki/Modding_Tutorials/Textures) and [art style guide](https://spdskatr.github.io/RWModdingResources/artstyle.html).

Start with one representative approved pilot per asset category. Use transparent PNG, flat fields, controlled dark outlines, namespaced texture paths and appropriate tile resolution. Audit direction consistency, proportions, apparel alignment, tint masks and in-game scale before producing a batch.

For reused assets record creator, source, license, revision, changes and attribution. Reference-only images must not be shipped. No third-party assets currently included.
