# 3D concept and sprite-reference material

- `kenney-mini-dungeon/`: five individually unpacked CC0 GLBs (human, orc, round shield, spear, sword) plus the complete 30-model converted Mini Dungeon ZIP. Human and orc contain named movement, combat, and interaction animations. Source: [Kenney Mini Dungeon](https://kenney.nl/assets/mini-dungeon); license file included. Convert and render references at the target sprite perspective and scale rather than importing these low-poly models directly into the game.

The exported sample models were imported in Blender; this does not verify RimWorld sprite parity or in-game loading. These are reference inputs for a future art workflow, not finalized Orcish Hordes assets.
