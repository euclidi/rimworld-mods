# Reusable RimWorld modding resources

These are development resources, not installable mods and not integrated into Orcish Hordes.

- `tech/quickstarts/`: source and project files for RimWorks Quickstarts at commit `a6f3ef09c95aeacee163002f31b6d0e83f62f3a7`, https://github.com/RimWorks/Rimworld-Quickstarts . MIT license included. The upstream metadata lists 1.7; this copy has not been built or run here. The source requires external game references and RimLogging and a patch backend; read the upstream README before attempting a build. No game binaries or dependencies are included.
- `kenney-fantasy-ui/`: default-size panels, borders and dividers from [Fantasy UI Borders](https://kenney.nl/assets/fantasy-ui-borders), CC0, license included.
- `kenney-icons/`: selected 64px icons from [Board Game Icons](https://kenney.nl/assets/board-game-icons), CC0, license included.

Kenney files are unchanged subsets from `D:/Assets`. These are optional concept/UI source material, not approved RimWorld-style art; adapt and review against the art pilot and in-game scale before shipping. Preserve license and provenance when copying.
