# Reusable RimWorld modding resources

- [Directional sprite references](sprite-references/README.md): transparent human and orc idle, walk, and sprint frames, three prop studies, and a Blender rebuild script.

Development references for mod and art experiments; these are not installable mods and are not integrated into Orcish Hordes.

- [Foundational 3D source material](foundations-3d/README.md): humanoid/orc models, animation clips, shields, and melee weapons for concept and sprite-reference work.
- `foundations-3d/kenney-mini-dungeon/kenney-mini-dungeon-full.zip`: complete 30-model converted Mini Dungeon pack, alongside the small unpacked human/orc/weapon/shield examples.
- `kenney-fantasy-ui/`: default-size panels, borders, and dividers from [Fantasy UI Borders](https://kenney.nl/assets/fantasy-ui-borders), CC0, license included.
- `kenney-icons/`: selected 64px icons from [Board Game Icons](https://kenney.nl/assets/board-game-icons), plus the complete source archive in `kenney-icons-full/`; CC0, license included.
- `tech/quickstarts/`: RimWorks Quickstarts source and project files at commit `a6f3ef09c95aeacee163002f31b6d0e83f62f3a7`, [upstream repository](https://github.com/RimWorks/Rimworld-Quickstarts). MIT license included. Its metadata lists 1.7; this copy has not been built or run here. External game references, RimLogging, and a patch backend are required; read the upstream README before a build. No game binaries or dependencies are included.

Kenney assets are optional source material, not approved RimWorld-style art or game-ready textures. Adapt them against the art pilot and in-game scale before shipping. Preserve license and provenance when copying.
